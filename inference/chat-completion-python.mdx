以下是使用 Ubicloud 託管 AI 推論端點的逐步 Python 教學。
本指南專注於 Python 筆記本環境，如 Google Colab 或 Jupyter Notebook，但也適用於在本地執行 Python 腳本的標準 pip 環境。
所有腳本和範例都可在此 [Google Colab Notebook](https://colab.research.google.com/drive/1jKedtEzpAJx5Tzn7KuYZUoM0ti5UJkXK?usp=sharing) 中取得。

## 概念概述

* Ubicloud AI 推論端點：這些端點託管與 OpenAI API 相容的 AI 模型。這意味著您可以使用熟悉的 OpenAI Python SDK 與這些模型互動。

* OpenAI Python SDK：
OpenAI SDK 簡化了向 AI 模型發送請求和處理回應的過程。您將使用它來發送聊天提示、接收串流或完整回應，甚至請求結構化（JSON）輸出。

* API 金鑰和基礎 URL：
要驗證並向 Ubicloud 的端點發送請求，您需要您的 API 金鑰和端點的基礎 URL（兩者都可從您的 Ubicloud 儀表板取得）。

* 聊天完成模式：Ubicloud 支援多種與 AI 模型互動的方式：

  * 非串流：一次性返回完整回應。

  * 串流：逐步返回回應，對於長答案或即時處理非常有用。

  * JSON 輸出：將回應格式化為 JSON 物件，用於結構化資料提取。

  * 工具呼叫：在需要時呼叫工具。

## 匯入程式庫並設定您的環境

匯入必要的程式庫並設定您的環境。這裡我們使用 Colab 的內建方法來檢索儲存的使用者資料。如果您在另一個筆記本平台上，請相應地調整 API 金鑰檢索。

```python
from google.colab import userdata  # 這是 Colab 特有的；如果使用其他環境請調整。
import json
import openai

# 檢索您的 Ubicloud API 金鑰（替換為您儲存或檢索憑證的方法）
INFERENCE_API_KEY = userdata.get("UBICLOUD_API_KEY")  # 或簡單地：INFERENCE_API_KEY = "your_api_key_here"

# 從您的 Ubicloud 儀表板定義模型名稱和基礎 URL
MODEL = "llama-3-3-70b-turbo"  # 範例模型；根據需要更新。
BASE_URL = f"https://{MODEL}.ai.ubicloud.com/v1"

# 建立為 Ubicloud 端點配置的 OpenAI 客戶端實例。
client = openai.OpenAI(
    api_key=INFERENCE_API_KEY,
    base_url=BASE_URL
)
```

`INFERENCE_API_KEY` 用於驗證您的請求。
`MODEL` 和 `BASE_URL` 特定於您選擇的模型和 Ubicloud 部署。

## 範例 1：非串流聊天完成

在此範例中，您將向模型發送一個簡單的聊天訊息，並一次性列印完整回應。

```python
# 非串流聊天完成：發送一個簡單的訊息並獲得完整回應。
completion = client.chat.completions.create(
    model=MODEL,
    messages=[
        {
            "role": "user",
            "content": "Say this is a test",
        },
    ],
)

# 從模型列印回應訊息。
print(completion.choices[0].message.content)
```

messages 參數是表示對話的字典列表。
回應透過 `completion.choices[0].message.content` 存取。

## 範例 2：串流聊天完成

此範例示範如何以串流方式（逐塊）接收模型的輸出。這在處理長回應或當您想在整個回應準備好之前開始處理輸出時特別有用。

```python
# 串流聊天完成：回應以塊的形式返回。
stream = client.chat.completions.create(
    model=MODEL,
    messages=[
        {
            "role": "user",
            "content": "How do I print hello world in Python?",
        },
    ],
    stream=True,  # 啟用串流模式。
)

# 迭代回應塊並在接收時列印它們。
for chunk in stream:
    if not chunk.choices:
        continue  # 如果此塊中沒有選擇，則跳過。

    # 列印每個內容片段，不換行，直到完整訊息完成。
    print(chunk.choices[0].delta.content, end="")

# 最後，在串流輸出後列印換行。
print()
```

設定 `stream=True` 告訴 API 在部分結果可用時返回它們。
迴圈迭代每個塊並列印訊息的 delta（最新新增）。

## 範例 3：帶有 JSON 輸出的聊天完成

在某些情況下，您可能希望模型產生結構化輸出，例如 JSON 物件。此範例顯示如何直接從模型請求 JSON 輸出。

```python
json_completion = client.chat.completions.create(
    model=MODEL,
    messages=[
        {
            "role": "user",
            "content": """
I have three apples and two bananas.
Generate a JSON object with two fields: apple and banana.
Each field should represent the respective count of the mentioned fruits.
""",
        },
    ],
    response_format={"type": "json_object"},  # 請求 JSON 輸出。
)

# 將 JSON 字串載入到 Python 字典中。
result = json.loads(json_completion.choices[0].message.content)
print(result)
```

提示指示模型輸出 JSON 物件。
response_format 參數指定預期的輸出是 JSON 物件。
`json.loads()` 函式將 JSON 格式的字串轉換為 Python 字典，以進行進一步操作。

## 範例 4：帶有工具呼叫的聊天完成

您可以定義模型可以呼叫以執行特定任務的工具（函式）。以下是如何設定計算器函式並使用模型的函式呼叫功能整合它：

```python
# 定義計算器函式
def calculator(expression: str):
    try:
        result = eval(expression)  # 警告：使用 eval 不安全！
        return {"result": result}
    except Exception as e:
        return {"error": str(e)}

# 定義任務
TASK = "Calculate 123*456+789"

# 定義工具
TOOLS = [{
    "type": "function",
    "function": {
        "name": "calculator",
        "description": "Evaluate a basic arithmetic expression",
        "parameters": {
            "type": "object",
            "properties": {
                "expression": {
                    "type": "string",
                    "description": "The arithmetic expression to evaluate, e.g., '2+2'"
                }
            },
            "required": ["expression"]
        }
    }
}]

# 建立帶有工具呼叫的聊天完成
tool_completion = client.chat.completions.create(
    model="gpt-3.5-turbo",
    messages=[{"role": "user", "content": TASK}],
    tools=TOOLS,
    tool_choice="auto"
)

# 處理工具呼叫
message = tool_completion.choices[0].message
if message.tool_calls:
    tool_call = message.tool_calls[0].function
    arguments = json.loads(tool_call.arguments)
    tool_result = calculator(**arguments)
    print(f"Function called: {tool_call.name}")
    print(f"Arguments: {arguments}")
    print(f"Result: {tool_result}")
else:
    print("No tool call detected in the response.")
```

在進行聊天完成請求時，我們包含工具並設定 tool_choice="auto"，以便模型可以決定是否呼叫它。如果發生工具呼叫，我們提取函式名稱和參數，執行計算器，並列印結果。如果需要與模型進行進一步互動，我們可以根據計算器的結果建構新訊息。
