---
title: '調整叢集大小'
---

您可以隨時調整 Kubernetes 叢集的大小，以滿足不斷變化的工作負載需求、提高資源利用率或降低基礎設施成本。調整 Kubernetes 叢集大小會通過添加或移除節點來更改工作節點池中的節點數量。這可以通過網頁介面、CLI 或 API 完成。

## 查看叢集的當前大小

您可以在叢集頁面的 **Overview** 選項卡中查看叢集的設定大小，並在 **Nodes** 選項卡中查看節點的詳細資訊。

![節點](/managed-kubernetes/nodes-screenshot.png)

## 通過網頁介面調整大小

1. 在 [Ubicloud 控制台](https://console.ubicloud.com)中導航到 Kubernetes 頁面。
2. 點擊您要調整大小的叢集名稱。
3. 點擊 **Settings** 選項卡。
4. 在 **Resize Worker Node Pool** 部分，選擇所需的節點數量並點擊 **Resize** 按鈕。

![調整工作節點池大小](/managed-kubernetes/resize-screenshot.png)

## 通過 CLI 調整大小

您也可以使用 [`ubi`](https://www.ubicloud.com/docs/quick-start/cli) CLI 工具的 `resize-nodepool` 命令來調整叢集大小：

```bash
ubi kc (location/kc-name | kc-id) resize-nodepool (np-name | np-id) node-count
```

## 通過 API 調整大小

要使用 API 調整叢集大小，請向 `kubernetes-cluster/{cluster_ref}/nodepool/{nodepool_ref}/resize` 端點發送 `POST` 請求，並在請求正文中包含所需的節點數量：

```http
POST https://api.ubicloud.com/project/{project_id}/location/{location}/kubernetes-cluster/{kubernetes_cluster_reference}/nodepool/{kubernetes_nodepool_reference}/resize
Content-Type: application/json

{
  "node_count": <node-count>
}
```

您可以在 API 文件中找到更多資訊：[更改 Kubernetes 節點池的節點數量](https://www.ubicloud.com/docs/api-reference/kubernetes-cluster/change-number-of-nodes-of-a-kubernetes-nodepool)。
