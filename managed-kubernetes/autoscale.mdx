---
title: '自動擴展'
---

Kubernetes 中的自動擴展對於運行具有彈性、成本效益和性能優化的雲原生應用程式至關重要。Kubernetes 自動擴展讓您的基礎設施能夠通過自動調整資源來適應不斷變化的需求。通過啟用水平 Pod 自動擴展和垂直 Pod 自動擴展等方法，Ubicloud Kubernetes 確保您的應用程式具有性能和效率。

## 水平 Pod 自動擴展 (HPA)
水平 Pod 自動擴展是 Kubernetes 的內建功能。它允許您根據使用情況自動擴展部署中的 Pod 數量。

<Note>HPA 需要在 K8s 叢集中安裝 `metrics-server`，Ubicloud Kubernetes 預設會為您處理這個問題。</Note>

以下是查看 HPA 運作的快速演練，摘自 [Kubernetes 文件](https://kubernetes.io/docs/tasks/run-application/horizontal-pod-autoscale-walkthrough/)，假設您已經啟動了 Ubicloud Kubernetes 叢集並使用 kubeconfig 文件設置了終端：

**部署範例網頁應用程式**
```bash
kubectl apply -f https://k8s.io/examples/application/php-apache.yaml
```

這將創建一個範例網頁應用程式和一個服務，以在叢集內公開它。

**創建水平 Pod 自動擴展規則**
```bash
kubectl autoscale deployment php-apache --cpu-percent=50 --min=1 --max=10
```

**觀察水平 Pod 自動擴展行為**
```bash
kubectl get hpa --watch
```

**生成負載**

在另一個終端視窗中，運行以下命令為網頁應用程式生成負載，並在幾分鐘內查看水平 Pod 自動擴展器增加副本數量
```bash
kubectl run -i --tty load-generator --rm --image=busybox:1.28 --restart=Never -- /bin/sh -c "while sleep 0.01; do wget -q -O- http://php-apache; done"
```

當您生成負載時，Pod 的 CPU 使用率應該會增加，副本數量也會增加。

當您取消負載生成器命令時，您可以觀察到 HPA 會自動減少副本數量。

## 垂直 Pod 自動擴展 (VPA)
Kubernetes 中的垂直 Pod 自動擴展器 (VPA) 會根據觀察到的使用情況自動調整 Pod 的 CPU 和記憶體請求。它非常適合資源需求不可預測或不適合水平擴展的工作負載，有助於確保穩定性和高效利用，而無需手動調整。與 HPA 不同，垂直 Pod 自動擴展器並未內建在 Kubernetes 中，需要通過[官方 VPA 存儲庫](
https://github.com/kubernetes/autoscaler/tree/9f87b78df0f1d6e142234bb32e8acbd71295585a/vertical-pod-autoscaler)單獨安裝。

```bash
# 取得 VPA
git clone https://github.com/kubernetes/autoscaler.git
cd autoscaler/vertical-pod-autoscaler

# 在叢集中安裝 VPA 組件
./hack/vpa-up.sh

# 驗證 VPA 安裝
kubectl get pods -n kube-system | grep vpa
```

此時，您應該會在 `kube-system` 命名空間中看到三個 VPA 組件正在運行：`vpa-admission-controller`、`vpa-recommender` 和 `vpa-updater`。

**創建範例應用程式**

```bash
kubectl apply -f https://k8s.io/examples/application/php-apache.yaml
kubectl scale deployment php-apache --replicas=2
```

**為範例應用程式創建 VPA 物件**

```bash
kubectl apply -f <(cat <<EOF
apiVersion: autoscaling.k8s.io/v1
kind: VerticalPodAutoscaler
metadata:
  name: php-apache-vpa
spec:
  targetRef:
    apiVersion: "apps/v1"
    kind:       Deployment
    name:       php-apache
  updatePolicy:
    updateMode: "Recreate"
EOF
)
```

**生成負載**

在另一個終端視窗中，運行以下命令為網頁應用程式生成負載：
```bash
kubectl run -i --tty load-generator --rm --image=busybox:1.28 --restart=Never -- /bin/sh -c "while sleep 0.01; do wget -q -O- http://php-apache; done"
```

觀察垂直 Pod 自動擴展器對部署的建議以及有關使用更高資源限制重新創建 Pod 的事件

```bash
kubectl describe vpa php-apache-vpa
```

如果您想清理叢集，可以卸載 VPA：

```bash
./hack/vpa-down.sh
```

## 叢集自動擴展（節點自動擴展）
叢集自動擴展根據工作負載需求動態調整 Kubernetes 叢集中的節點數量。雖然 Ubicloud Kubernetes 目前不支持此功能，但我們正在努力啟用叢集自動擴展。您可以通過 [support@ubicloud.com](mailto:support@ubicloud.com) 與我們聯繫，提供您的反饋和功能請求。
