---
title: '託管服務'
---

在本指南中，您將註冊 Ubicloud，建立虛擬機器（VM）和虛擬網路，並使用 SSH 連接到您的 VM。對於這個專用 VM，您支付的費用比 AWS 或 Azure 低約 3 倍。

## 註冊並登入

您可以在不安裝任何東西的情況下使用 Ubicloud：[https://console.ubicloud.com/create-account](https://console.ubicloud.com/create-account)。首次使用 Ubicloud 時，您需要建立一個新帳戶。完成後並登入，您將被導向到 Ubicloud 的首頁。

## 輸入帳單詳細資訊

Ubicloud 控制台的首頁向您顯示可用的雲端服務。它還讓您使用專案與他人協作，您可以在其中邀請新使用者並定義細粒度權限。

預設情況下，Ubicloud 專案使用 Hetzner 作為裸機託管提供商。每個託管提供商都有不同的價格、實例類型和地理位置可用性。

![Enter billing Details](/quick-start/managed-services-1-screenshot.png)

我們要求在您建立資源之前檔案中有一張有效的信用卡。

<Note>
  需要預先授權最多 $5 以驗證您的卡。此金額不會被收費，並將在驗證後取消。根據您的銀行，可能需要長達兩週的時間才能退款。
</Note>

這主要是為了防止濫用並確保我們可以在月底收取付款。從左側導航選單中，選擇 Billing。然後，輸入您的信用卡資訊。

## 建立虛擬機器（VM）

在導航選單上，選擇 Compute 服務，然後點擊 New Virtual Machine。這將帶您進入 VM 建立頁面。

在這裡，您可以選擇您的區域、伺服器系列和大小以及 Linux 發行版。您還需要新增您的公共 SSH 金鑰，以便在建立後可以連接到 VM。

我們提供兩個伺服器系列 - Standard 和 Burstable。Standard 提供專用 CPU 和每個 vCPU 4GB 記憶體。它最適合您的通用和最苛刻的工作負載。Burstable 提供共享 CPU 和每個 vCPU 2GB 記憶體。它最適合可變工作負載、低流量網站、開發和測試工作負載以及 AI 代理。

預設情況下，我們為每個 VM 建立一個私有子網路。如果您有現有的私有子網路，也可以選擇在該子網路中建立 VM。每個 VM 在您的虛擬網路中獲得一個私有 IPv4 和 IPv6 位址。VM 還免費獲得一個公共 IPv6 位址，預設情況下以小額費用獲得一個公共 IPv4 位址。

完成所有必填欄位後，點擊 Create 建立您的 VM。在 1-2 分鐘內，您的 VM 應該準備好連接。

![Create virtual machine](/quick-start/managed-services-2-screenshot.png)

## 連接到您的 VM

建立 VM 後，您可以使用 SSH 連接到它。

首先，您必須從控制台複製公共 IPv4（或 IPv6）位址。然後在您的終端機中，只需輸入：

```bash
ssh <user_name>@<ip_address>

# 如果您在建立 VM 時沒有更改預設使用者名稱，可以執行：

ssh ubi@<ip_address>
```

<Info>
  **摘要：** 在本快速入門指南中，您建立了一個 VM。VM 附帶本地區塊儲存，並有自己的虛擬私有網路。資料在靜態和傳輸中都經過加密；您可以使用基於屬性的存取控制（ABAC）與他人協作。如果您使用預設提供商，此 VM 的成本比在類似雲端區域中使用 AWS 低 3 倍。
</Info>
