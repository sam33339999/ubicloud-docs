---
title: '建構您自己的雲端'
---

在本指南中，您將在裸機提供商上建構自己的雲端。您將設定 Ubicloud 的控制平面，為資料平面租用裸機實例，並將這些裸機實例雲端化。一旦雲端化，您就可以使用彈性運算、虛擬網路和（本地）區塊儲存服務。

## 建立您的控制平面

Ubicloud 遵循建構公共雲端服務的既定架構模式。控制平面管理資料平面，其中資料平面利用開源軟體。

首先，複製 Ubicloud 專案並在您的本地環境中初始化控制平面。然後，連接到雲端控制台。

```bash
git clone git@github.com:ubicloud/ubicloud.git

# 為示範生成秘密
./demo/generate_env

# 執行容器：db-migrator、app（web 和 respirate）、postgresql
docker-compose -f demo/docker-compose.yml up

# 造訪 localhost:3000
```

初始化控制平面後，建立新使用者並登入雲端控制台。

## 為資料平面租用裸機實例

您現在需要為資料平面租用實例。最簡單的方法是從裸機提供商租用實例。Hetzner 提供伺服器競標，您按月支付裸機費用：[https://www.hetzner.com/sb](https://www.hetzner.com/sb)

租用實例後，使用以下環境變數更新 `.env` 檔案：
- `HETZNER_USER`
- `HETZNER_PASSWORD`
- `HETZNER_SSH_PUBLIC_KEY`
- `HETZNER_SSH_PRIVATE_KEY`

## 雲端化您的實例

為您想要雲端化的每個實例執行以下腳本。目前，該腳本僅雲端化從 Hetzner 租用的裸機實例。雲端化實例後，您可以在這些機器上佈建和管理資源。

```bash
docker exec -it ubicloud-app ./demo/cloudify_server
```

## 建立虛擬機器（VM）

現在，您可以登入 localhost:3000 的控制台並建立 VM。Ubicloud 將在虛擬網路中建立每個 VM，並為其分配私有 IPv4/IPv6 位址。它還將為 VM 分配公共 IPv6 位址。

如果您的 ISP 不支援 IPv6，請使用 VPN 或隧道代理，例如 Mullvad 或 Hurricane Electric 的 [https://tunnelbroker.net](https://tunnelbroker.net)。或者，您可以從提供商租用 IPv4 位址並將其新增到控制平面。

<Info>
    **摘要：** 在本快速入門指南中，您在裸機提供商上建構了自己的雲端。然後，您可以使用 Ubicloud 隨附的標準雲端服務，例如運算、虛擬網路和本地區塊儲存。
</Info>
