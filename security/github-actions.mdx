Ubicloud 致力於保護客戶資料的安全。您可以在[一般安全頁面](/security/overview)中閱讀更多關於我們的安全實踐。本頁面分享了與我們的 GitHub Actions 整合相關的某些最佳實踐。

## 每個作業使用乾淨且短暫的 VM

Ubicloud 使用 VM 來安全地隔離您的資料與其他使用者。對於每個新的 CI/CD 作業，我們還為您提供一個乾淨且短暫的 VM。作業完成後，我們會停用 VM 並刪除與 VM 關聯的區塊儲存裝置。

這確保了沒有方法可以持續破壞 GitHub Actions 環境，或以其他方式獲得對在引導程序期間放置在此環境中的資訊之外的更多資訊的存取權限。

## 使用即時 Runner

Ubicloud 遵循 GitHub 的建議，使用[即時（JIT）runner API](https://docs.github.com/en/actions/security-guides/security-hardening-for-github-actions#using-just-in-time-runners) 來改善 runner 註冊安全性。我們使用 GitHub 的 REST API 從 GitHub 建立並接收 JIT 配置檔案，並在啟動時將此檔案傳遞給 Ubicloud runner。我們不會以任何方式儲存此 JIT 配置檔案。

這確保了我們建立短暫的 JIT runner。這些 runner 在從儲存庫中自動移除之前最多執行一個作業

## 日誌保留

我們保留包含有關 CI/CD 作業資訊的元資料日誌，包括啟動者、開始時間、持續時間和選定的硬體。透過此元資料，我們可以維護稽核日誌並在發生任何安全事件時更詳細地分析它們。
