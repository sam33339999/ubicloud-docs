---
title: '遷移到 Arm runners'
---

GitHub Actions 在 x64 架構上執行。如果您正在為 arm64 架構建置或測試，並使用 QEMU 模擬來執行此操作，您可以變更您的工作流程檔案以原生使用 arm64。

為此，您只需變更您的平台並移除 QEMU 步驟。

![Migrate to Arm runners](/github-actions-integration/migrate-to-arm-runners-1.png)

## Arm 映像

GitHub Actions 目前沒有官方的 Arm 映像可用。因此，Ubicloud 建立了自己的 Ubuntu 映像；而我們的 Arm runners 沒有 x64 上可用的所有預安裝套件。

如果您的工作流程有 Ubicloud 的 arm 映像上不存在的套件依賴項，我們建議暫時手動安裝該依賴項。

如果您是大型客戶並需要 arm64 上的常用套件，可以聯繫我們 [support@ubicloud.com](mailto:support@ubicloud.com)。
