## 價格
Ubicloud 執行器相較於 GitHub 執行器提供了許多價格效能優勢。這些優勢包括：

- 價格比 GitHub Actions 便宜 10 倍
- Ubicloud 執行器即使在此價格點上也優於 GitHub 執行器
- 如果您選擇自行管理基礎設施，Ubicloud 雲端服務採用 AGPL v3 授權的開源方案

我們僅按使用量收費，並以每分鐘為單位計費。每個帳戶每月可獲得 $1 的額度，相當於 1,250 分鐘的 Ubicloud（2 vCPU）執行器時間。您可以在[一般定價頁面](/about/pricing#github-actions)中閱讀更多關於我們 Linux x64 和 Arm64 的價格資訊。

## 效能

除了成本效益高出 10 倍外，Ubicloud 執行器也更快。這是因為 Ubicloud 虛擬機在比 GitHub 的 Azure 虛擬機更新的硬體上執行。
