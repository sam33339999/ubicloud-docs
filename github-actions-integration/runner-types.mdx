---
title: '執行器類型'
---

Ubicloud 提供多種執行器類型和大小，讓您可以根據特定需求進行選擇。

預設情況下，使用 `runs-on: ubicloud` 會配置 2 vCPU x64 Ubuntu 22.04 執行器。您可以指定執行器大小，例如 `runs-on: ubicloud-standard-8` 會配置 8 vCPU 執行器。您甚至可以指定作業系統，例如 `runs-on: ubicloud-standard-4-ubuntu-2404`，會配置 4 vCPU、Ubuntu 24.04 的執行器。

## Ubuntu 24.04 遷移
所有預設 Ubicloud 執行器類型使用的作業系統將在 11 月 23 日從 Ubuntu 22.04 更新至 Ubuntu 24.04。所有使用標籤 `ubicloud`、`ubicloud-standard-2`、`ubicloud-standard-4`、`ubicloud-standard-8`、`ubicloud-standard-16`、`ubicloud-standard-30`、`ubicloud-standard-60`、`ubicloud-arm`、`ubicloud-standard-2-arm`、`ubicloud-standard-4-arm`、`ubicloud-standard-8-arm`、`ubicloud-standard-16-arm`、`ubicloud-standard-30-arm` 或 `ubicloud-standard-60-arm` 的作業將開始使用 Ubuntu 24.04。您可以透過在執行器標籤中明確指定作業系統版本來使用 Ubuntu 22.04，例如使用 `ubicloud-standard-2-ubuntu-2204` 而不是 `ubicloud-standard-2`。


## 可用標籤

| 工作流程標籤             | 作業系統           | vCPU | 記憶體 | 磁碟  |
|----------------------------|--------------|------|--------|-------|
| `ubicloud-standard-2`      | Ubuntu 22.04 | 2    | 8GB    | 86GB  |
| `ubicloud-standard-4`      | Ubuntu 22.04 | 4    | 16GB   | 150GB |
| `ubicloud-standard-8`      | Ubuntu 22.04 | 8    | 32GB   | 200GB |
| `ubicloud-standard-16`     | Ubuntu 22.04 | 16   | 64GB   | 300GB |
| `ubicloud-standard-30`     | Ubuntu 22.04 | 30   | 120GB  | 400GB |
| `ubicloud-standard-2-arm`  | Ubuntu 22.04 | 2    | 6GB    | 86GB  |
| `ubicloud-standard-4-arm`  | Ubuntu 22.04 | 4    | 12GB   | 150GB |
| `ubicloud-standard-8-arm`  | Ubuntu 22.04 | 8    | 24GB   | 200GB |
| `ubicloud-standard-16-arm` | Ubuntu 22.04 | 16   | 48GB   | 300GB |
| `ubicloud-standard-30-arm` | Ubuntu 22.04 | 30   | 90GB   | 400GB |

您可以附加 `-ubuntu-2204` 或 `-ubuntu-2404` 來明確設定作業系統。

Ubicloud 執行器支援以下標籤模式：

```yaml
# x64 執行器
runs-on: ubicloud-standard-{vcpu}-{os}
# ubicloud                        -> 2 vCPU x64 Ubuntu 22.04 執行器
# ubicloud-standard-8             -> 8 vCPU x64 Ubuntu 22.04 執行器
# ubicloud-standard-4-ubuntu-2404 -> 4 vCPU x64 Ubuntu 24.04 執行器

# arm64 執行器
runs-on: ubicloud-standard-{vcpu}-arm-{os}
# ubicloud-arm                        -> 2 vCPU arm64 Ubuntu 22.04 執行器
# ubicloud-standard-8-arm             -> 8 vCPU arm64 Ubuntu 22.04 執行器
# ubicloud-standard-4-arm-ubuntu-2404 -> 4 vCPU arm64 Ubuntu 24.04 執行器
```

## x64 執行器

Ubicloud x64 **標準執行器**由 AMD EPYC 9454P 處理器驅動，每兩個 x64 vCPU 對應一個實體核心。所有 Ubicloud 執行器都配備現代硬體，包括新一代處理器、NVMe SSD 和高速網路。這使我們能夠在我們的服務中提供更好的價格效能。

對於尋求更高效能的客戶，我們提供由 AMD Ryzen 9 7950X3D CPU 驅動的 **進階執行器**。這些處理器針對單執行緒速度和快速 CI 執行進行最佳化，非常適合大型 monorepos、測試密集型工作流程，或任何受益於高 CPU 時脈速度的作業。了解如何啟用進階執行器請參閱[這裡](/github-actions-integration/use-premium-runners)。

我們的 x64 執行器映像與預設執行器完全相容。我們使用 GitHub 在 [actions/runner-images](https://github.com/actions/runner-images) 儲存庫中發布的官方 HashiCorp packer 範本生成它們。

我們在 GitHub 發布新版本後每月更新映像。我們不會在與 GitHub 同一天部署新映像，以避免潛在的問題。過去，GitHub 在新映像上遇到過問題，不得不快速回退。

為了防止對我們的客戶造成任何中斷，我們通常在 GitHub 部署完成後幾天部署新映像。

如果您注意到 Ubicloud x64 執行器與官方 GitHub 執行器之間有任何不匹配，請透過 support@ubicloud.com 與我們聯繫。

如果您的工作流程有 Ubicloud 映像上不存在的套件依賴項，我們建議暫時手動安裝依賴項，或在 [actions/runner-images](https://github.com/actions/runner-images) 儲存庫中建立議題。

## arm64 執行器

Ubicloud arm64 執行器由 Ampere Altra Q80-30 處理器驅動，每個 arm64 vCPU 都有專用的實體核心支援。這確保了您工作負載的一致、高效能運算。

GitHub 在 2025 年初推出了官方 arm64 執行器。但是，GitHub 不建立 arm64 映像；他們的合作夥伴建立。不幸的是，他們不像 x64 映像那樣發布 packer 範本。因此，Ubicloud 建立自己的 Ubuntu arm64 映像，我們的 arm64 執行器沒有 x64 上可用的所有預安裝套件。

Arm 在 [actions/partner-runner-images](https://github.com/actions/partner-runner-images) 儲存庫中分享已安裝套件的列表，我們嘗試保持相似。但是，我們的映像可能與 GitHub 的 arm64 映像不完全相同，因為他們不分享確切的範本和版本。

如果您的工作流程有 Ubicloud arm64 映像上不存在的套件依賴項，我們建議暫時手動安裝依賴項。

如果您需要 arm64 上已在 x64 上安裝的常用套件，請透過 support@ubicloud.com 與我們聯繫。
