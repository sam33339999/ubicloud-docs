---
title: 'Ubicloud Cache'
---

本指南描述如何將您的 GitHub Action 工作流程與 Ubicloud Cache 整合。

Ubicloud 為每個新工作流程作業啟動一個乾淨且臨時的 VM，以確保安全性。新的 VM 需要下載作業依賴項，導致網路使用量增加、執行時間更長和成本更高。GitHub Actions cache 允許在工作流程作業之間共享依賴項和其他常用檔案。

Ubicloud Cache 透過將快取檔案儲存在更靠近 Ubicloud runners 的位置來改進 GitHub Actions cache，使快取下載/上傳更可靠且快達 4 倍。Ubicloud Cache 為每個儲存庫每週提供 30 GB 的免費儲存空間，是 GitHub 預設快取大小的 3 倍。如果您超過此限制，最舊的快取將自動刪除以騰出空間給新快取。此外，過去七天內未存取的快取也會自動刪除。

有兩種方式可以使用 Ubicloud Cache：

1. [Ubicloud Transparent Cache](#ubicloud-transparent-cache)（推薦）
2. [Ubicloud Cache Actions](#ubicloud-cache-actions)

## Ubicloud Transparent Cache

這是使用 Ubicloud 快取基礎設施的推薦方式。Transparent cache 在使用 Ubicloud 的 runners 時為您提供極大的靈活性，允許您在 Ubicloud 的 runners 和 GitHub 的預設 runners 之間切換，而無需修改工作流程檔案。

<Note>Transparent cache 預設啟用。如果您需要停用它，可以在 Ubicloud 控制台中執行此操作。</Note>

Transparent cache 支援所有快取檔案的 actions，包括：

- **檔案/資料夾快取**與 `actions/cache`：快取特定檔案或目錄，如依賴項或建置輸出，以加速工作流程。

- **套件管理器快取**與 `actions/setup-*`：自動快取語言的依賴項，例如 Python（`actions/setup-python`）、Node.js（`actions/setup-node`）和 Go（`actions/setup-go`）。某些語言（如 Rust（`Swatinem/rust-cache`））也支援第三方 actions。

- **Docker Layer 快取**與 `docker/build-push-action`：透過使用 `type=gha` 快取未變更的層來加速容器建置：

```yaml
- name: Build and push Docker images
  uses: docker/build-push-action
  with:
    cache-from: type=gha
    cache-to: type=gha
```

Transparent cache 在 Ubicloud runners 上將下載效能提升 4 倍，上傳效能提升 3 倍，並持續努力進一步增強上傳速度。

如需深入了解其實作和詳細的效能指標，請查看 [GitHub Actions Transparent Cache 部落格文章](https://www.ubicloud.com/blog/github-actions-transparent-cache)。

## Ubicloud Cache Actions

Ubicloud Cache Actions 是 `actions/cache` 作為 `ubicloud/cache` 和 `actions/setup-*` 作為 `ubicloud/setup-*` 的直接替代品。

它需要您變更工作流程檔案中的 action 名稱。它也不支援 docker layer 快取。使用 Ubicloud Cache Actions 相對於 Transparent Cache 的唯一優勢是它具有 65% 更好的儲存效能，因為它經過最佳化以增加檔案上傳期間的併發性。我們正在努力改進 Transparent Cache 的上傳效能以匹配它。

### 遷移到 `ubicloud/cache`

在工作流程中將 `actions/cache` 替換為 `ubicloud/cache`。Ubicloud Cache 完全支援 GitHub Actions Cache 功能。


```yaml
- uses: actions/cache@v4
+ uses: ubicloud/cache@v4
with:
   path: ~/.cache/pip
   key: ${{ runner.os }}-pip-${{ hashFiles('**/requirements.txt') }}
   restore-keys: |
     ${{ runner.os }}-pip-
```

### 遷移到 Ubicloud 的特定語言快取 Actions

Ubicloud 為 `actions/setup-*` 提供了最佳化的替代品。要遷移，請在工作流程中將 `actions/setup-*` 替換為 `ubicloud/setup-*`。

### Java

```yaml
- uses: actions/setup-java@v4
+ uses: ubicloud/setup-java@v4
```

### .Net

```yaml
- uses: actions/setup-dotnet@v4
+ uses: ubicloud/setup-dotnet@v4
```

### Python

```yaml
- uses: actions/setup-python@v5
+ uses: ubicloud/setup-python@v5
```

### Go

```yaml
- uses: actions/setup-go@v5
+ uses: ubicloud/setup-go@v5
```

### NodeJS

```yaml
- uses: actions/setup-node@v4
+ uses: ubicloud/setup-node@v4
```

其他一些流行的語言有自己的 setup-* actions，不由 GitHub 維護。Ubicloud 為其中一些最流行的提供了替代品。

### Ruby

```yaml
- uses: actions/setup-ruby@v1
+ uses: ubicloud/setup-ruby@v1
```

### Rust

```yaml
- uses: Swatinem/rust-cache@v2
+ uses: ubicloud/rust-cache@v2
```
