Ubicloud PostgreSQL 為您處理備份、高可用性、健康監控和管理資料庫的許多其他方面，讓您可以專注於應用程式開發。

使用 Ubicloud PostgreSQL，您將獲得以下好處：
- 相較於類似的公有雲解決方案，具有 [10 倍的價格效能比](https://www.ubicloud.com/blog/time-to-rethink-postgresql-storage)
- 可在 Hetzner 資料中心使用
- 開源，如果您選擇自行管理 Ubicloud 受管理 PostgreSQL

## 建立受管理 PostgreSQL

**導航至 PostgreSQL 服務：** 從儀表板左側選單中選擇「PostgreSQL」選項。

![Overview 1](/managed-postgresql/overview-1-screenshot.png)

**建立 PostgreSQL 資料庫：** 按一下「+ 新增 PostgreSQL 資料庫」按鈕。這將帶您到一個新頁面，您可以根據需求選擇執行個體類型。

![Create PostgreSQL Database](/managed-postgresql/create-screenshot.png)

**執行個體設定：** 輸入所需的資料庫伺服器名稱並選擇所需的執行個體類型。您不需要設定其他任何內容。安全密碼將自動產生。

**執行個體建立：** 選擇執行個體類型後，按一下「建立」按鈕。您的受管理 PostgreSQL 執行個體將在幾分鐘內設定完成並準備就緒。

## 執行個體概述

執行個體概述頁面顯示 PostgreSQL 執行個體的狀態，包括執行個體類型、位置、HA 設定以及 CPU 和磁碟使用指標的摘要。
