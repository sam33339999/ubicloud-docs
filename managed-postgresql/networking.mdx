Ubicloud PostgreSQL 執行個體預設可透過網際網路存取。要根據用戶端的 IP 位址限制對資料庫的連線，您可以在網路檢視中設定防火牆規則。

![Networking view](/managed-postgresql/networking-screenshot.png)

## 新增和修改防火牆規則

防火牆規則定義允許連線到資料庫的 IP 位址範圍。您可以新增多個防火牆規則以允許來自不同 IP 範圍的連線。

要修改現有的防火牆規則，請按一下旁邊的「編輯」按鈕，根據需要變更 IP 範圍和描述，然後確認變更。
您也可以按一下旁邊的「刪除」按鈕來刪除防火牆規則。
要新增新的防火牆規則，請輸入 IP 範圍和描述，然後按一下「建立」按鈕。

對防火牆規則所做的任何變更通常會在一分鐘內生效。
