title: '價格效能比'
---

由於其基於 NVMe SSD 儲存的獨特架構，Ubicloud 受管理 PostgreSQL 相較於類似的受管理 PostgreSQL 服務提供 **10 倍**更好的價格效能比。以下基準測試比較了 Ubicloud PostgreSQL 與 AWS Aurora 和 AWS RDS PostgreSQL。

## TPC-C 基準測試
Ubicloud PostgreSQL 執行的交易數量比 AWS Aurora 多 **1.4 倍**，成本降低 **5.8 倍**。同樣地，Ubicloud Postgres 執行的交易數量比 AWS RDS 多 **4.6 倍**，成本降低 **2.8 倍**。Ubicloud PostgreSQL 的延遲也比 AWS Aurora 低 **1.91 倍**，比 AWS RDS PostgreSQL 低 **7.65 倍**。

基準測試設定：
- **Ubicloud**：standard-8（8 vCPUs，32 GB RAM）執行個體，配備 1 TB SSD 儲存
- **AWS Aurora**：db.r8g.2xlarge（8 vCPUs，64 GB RAM）執行個體，配備 1 TB SSD 儲存
- **AWS RDS**：db.m7g.2xlarge（8 vCPUs，32 GB RAM）執行個體，配備 I/O 最佳化儲存
- **資料表數量**：32
- **倉庫數量**：256
- **用戶端數量**：64

## TPC-H 基準測試
Ubicloud PostgreSQL 執行 22 個 TPC-H 查詢的速度比 AWS Aurora 快 **2.42 倍**，比 AWS RDS PostgreSQL 快 **2.96 倍**，同時成本比 AWS Aurora 低 **6.40 倍**，比 AWS RDS PostgreSQL 低 **3.00 倍**。

基準測試設定：
- **Ubicloud**：standard-8（8 vCPUs，32 GB RAM）執行個體，配備 512 GB SSD 儲存
- **AWS Aurora**：db.r8g.2xlarge（8 vCPUs，64 GB RAM）執行個體，配備 512 GB SSD 儲存
- **AWS RDS**：db.m7g.2xlarge（8 vCPUs，32 GB RAM）執行個體，配備 I/O 最佳化儲存
- **規模因子**：100
