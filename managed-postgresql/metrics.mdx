title: '指標'
---

Ubicloud PostgreSQL 執行個體的指標檢視提供各種訊號，用於監控 PostgreSQL 執行個體的效能和健康狀態。

![Metrics dashboard](/managed-postgresql/metrics-1-screenshot.png)

時間範圍下拉選單可讓您選擇圖表的時間範圍，從 30 分鐘到 30 天不等。每個圖表顯示約 480 個資料點。圖表每 5 分鐘自動更新一次。您也可以使用重新整理按鈕手動更新圖表。

如果您最近才佈建 PostgreSQL 資料庫，可能需要幾分鐘才能使用指標。對於啟用 HA 的資料庫，會顯示主節點的指標。

以下是提供的一些關鍵指標以及如何解讀它們的詳細資訊。

## 資源使用指標

### CPU 使用率

顯示 CPU 使用率，細分為 `user`、`system`、`iowait`、`softirq` 和 `steal` 模式下 CPU 時間的百分比。`user` 時間反映 Postgres 執行個體中的處理，而 `system` 時間反映作業系統（即核心）操作。

### 負載平均值

負載平均值顯示過去 1、5 和 15 分鐘的平均 CPU 使用率。通常，負載平均值等於 CPU 核心數量表示所有 CPU 完全利用。負載平均值高於 CPU 核心數量表示系統過載，處理程序正在等待 CPU 時間。

如果您持續看到高負載平均值，可能需要考慮升級到更大的資料庫大小。

### 記憶體使用量

顯示記憶體使用量，細分為已使用、快取和緩衝記憶體。大量記憶體用於快取和緩衝區是正常的，表示資料庫有效地使用可用記憶體。已使用記憶體持續偏高（> 90%）表示資料庫可能記憶體不足，這可能導致效能問題。

### 磁碟使用量

磁碟使用量是資料庫的磁碟空間利用率，特別是 Postgres `data_directory`。這包括資料庫內容、日誌檔案和 WAL 檔案等。如果您的執行個體接近 100% 的磁碟使用量，可能需要考慮升級到更大的資料庫大小。

### 磁碟 I/O

此指標顯示資料庫執行個體每秒的磁碟讀寫操作。此指標的高值可能表示資料庫正在經歷高 I/O 負載，這可能導致效能問題。

### 網路流量

此指標顯示資料庫執行個體的傳入和傳出網路流量。通常，這應該與執行個體的其他指標行為相符。此指標中的異常活動可能表示網路或資料庫執行個體本身存在問題。

## 資料庫效能指標

![Database Performance Metrics](/managed-postgresql/metrics-2-screenshot.png)

### 連線數

顯示已連線的 Postgres 用戶端的活動和總數。總連線數是指所有當前連線的用戶端，而活動連線數是指當前正在執行查詢的用戶端。預設情況下，最大連線數設定為 500。如果您的資料庫持續達到或接近此限制，可能需要考慮增加此限制或透過 PgBouncer 使用連線池。

### 快取命中率

此指標表示有多少內容請求是從快取提供的。對於正常工作負載，此值通常應該高於 99%。如果此值較低，可能表示資料庫效能可能會透過使用具有更多記憶體的較大執行個體而得到改善。

### 操作吞吐量

此圖表顯示每秒資料列擷取、插入、更新和刪除的速率。這對於識別使用模式的意外變化及其對資料庫效能的影響非常有用。

### 死鎖

此指標顯示資料庫中每秒偵測到的死鎖速率。當兩個或多個交易正在等待其他交易持有的資源時，就會發生死鎖，導致它們都無法繼續。非零或高值表示交易設計不良，這可能導致效能下降。

### 資料庫大小

此圖表顯示執行個體中 5 個最大資料庫的大小。這對於識別意外成長或需要清理或封存的資料庫非常有用。

### 交易

此圖表顯示每秒提交和回復的交易速率。這對於識別使用模式的意外變化及其對資料庫效能的影響非常有用。


## 指標目的地

可以將各種指標（如 CPU 使用率、磁碟 I/O、資料庫鎖定）從您的資料庫傳送到外部目標。指標目的地使用 Prometheus 的遠端寫入協定來傳送指標。任何支援遠端寫入協定的目的地都可以用作 Ubicloud PostgreSQL 指標的目的地。您可以在[這裡](https://prometheus.io/docs/operating/integrations/#remote-endpoints-and-storage)找到支援遠端寫入協定的目的地。

### 設定

設定指標目的地很簡單。只需開啟 PostgreSQL 伺服器詳細資訊頁面。您可以在「指標目的地」部分輸入遠端目的地的連線詳細資訊。

![Metric Destinations](/managed-postgresql/metric-destinations-1.png)

我們需要 3 項資訊：傳送指標的 URL，以及用於身分驗證的使用者名稱/密碼。我們只接受 https:// 端點。這樣我們確保傳送的資料在傳輸過程中經過加密。

### 指標類型

我們傳送兩種類型的指標：
- **來自資料庫本身的指標：** 資料庫指標由 [postgres_exporter](https://github.com/prometheus-community/postgres_exporter) 收集。它包含有關資料庫大小、活動連線、寫入/讀取活動、複製、WAL 封存、自動清理等的資訊。
- **來自底層虛擬機器的指標：** 虛擬機器指標由 [node_exporter](https://github.com/prometheus/node_exporter) 收集。它包含有關 CPU 使用率、磁碟 I/O、檔案系統使用量、記憶體消耗和網路傳輸的資訊。
