Ubicloud 在裸機服務商（例如 Hetzner、Leaseweb 或 AWS Bare Metal）上提供 IaaS 雲端功能。您可以自行在這些服務商上建置，或使用我們的託管服務。

以下定價資訊適用於我們的託管服務。計費基於已配置的資源，並按配置時間按比例計算。我們以每分鐘為單位計算資源使用量，並按月計費。

整體而言，我們的價格比同類服務低 3-10 倍。例如，不同服務的 2 vCPU 執行個體價格為：

- [GitHub Actions](#github-actions)：Ubicloud 每分鐘 \$0.0008 對比 GitHub 每分鐘 \$0.008
- [運算（虛擬機）](#compute)：Ubicloud 每月 \$26 對比 AWS 德國每月 \$90
- [託管 PostgreSQL](#managed-postgresql)：Ubicloud 每月 \$65 對比 AWS 德國每月 \$200
- [突發型虛擬機](#burstable-vms) 起價每月 \$6.65，[突發型託管 PostgreSQL](#burstable-postgresql) 起價每月 \$12.40


## GitHub Actions

Ubicloud 執行器配備專用 CPU、記憶體、本地區塊儲存和公共 IPv4 位址。我們的 GitHub 託管執行器應用程式在德國的數據中心配置虛擬機（VM），以提供高可用性。每個帳戶每月可獲得 \$1 的額度，相當於 1,250 分鐘的 Ubicloud 執行器時間。

標籤 `ubicloud-standard-2` 預設為 Linux x64 2 vCPU。考慮到 Ubicloud 的價格優勢，如果您的管道可從平行處理中受益，我們建議嘗試 4 個或更多 vCPU。

當您啟用進階執行器時，我們會自動將您的任務路由到進階機器。如果容量已滿，您會無縫回退到標準執行器，無需額外等待時間。您將根據所使用的執行器類型按分鐘計費。

### 突發型虛擬機

突發型虛擬機配備共用 CPU。每個虛擬機可使用最多 50% 的已配置 vCPU 主機容量，並可在微秒級間隔內額外突發至已配置 vCPU 的 100%。記憶體和區塊儲存目前為每個虛擬機專用。突發型虛擬機最適合低流量網站、開發和測試工作負載，以及 AI 代理。

### 網路

Ubicloud 在私有子網路中建立每個虛擬機。每個虛擬機免費獲得私有 IPv4 和 IPv6 位址。虛擬機還免費獲得公共 IPv6 位址。對於公共 IPv4 位址，我們按分鐘按比例收取每月 \$3.00 的費用。您可以在建立虛擬機時選擇不使用公共 IPv4。

每個虛擬機每 2 個 vCPU 有 0.625TB 的月度出口流量配額。如果超過此限制，我們將對每 TB 出口流量收取 \$3 的費用。我們不對入口流量或同一雲端地區內資源之間的流量收費。
