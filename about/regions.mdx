title: '地區'
---

Ubicloud 託管服務透過各種裸機服務商的數據中心提供，例如 Hetzner 和 Leaseweb。我們會根據需求新增新的服務商和地區。如果您對特定地區有興趣，請透過 [support@ubicloud.com](mailto:support@ubicloud.com) 與我們聯繫。

每個 Ubicloud 地區都可以對應到特定服務商及其數據中心。以下是現有 Ubicloud 地區的對應關係。

|  地區名稱  | 裸機服務商 |       位置       |
|:-------------:|:-------------------:|:--------------------:|
| eu-central-h1 |       Hetzner       | 德國福爾肯施泰因 |
|  eu-north-h1  |       Hetzner       |   芬蘭赫爾辛基  |
|   us-east-a2  |       Leaseweb      |   美國維吉尼亞州馬納薩斯   |

### Github Action 執行器

Github 執行器會根據配置時地區的整體可用性，自動在 `eu-central-h1` 或 `eu-north-h1` 地區配置。
