_客戶內容數據是指 Ubicloud 客戶或任何終端使用者在使用 Ubicloud 服務時為了處理、儲存或託管而傳輸給我們的內容，以及客戶或其終端使用者透過使用 Ubicloud 服務從前述內容衍生的任何運算結果。這包括我們 Ubicloud EuroGPT 服務輸入的數據，包括客戶和/或終端使用者提示，以及從中合法收到的輸出。這不包括客戶帳戶數據（如下所述）。我們的客戶保留此數據的完整所有權和控制權，我們通常無法確定客戶是否在其客戶內容數據中處理個人數據。請參閱我們的[服務條款](/about/terms-of-service)。如果您是位於歐洲經濟區的客戶，正在使用歐洲經濟區的 Ubicloud 託管服務，且您或您的終端使用者的客戶內容數據包含個人數據，請透過 [info@ubicloud.com](mailto:info@ubicloud.com) 與我們聯繫以請求簽署數據處理協議_

所有 Ubicloud 託管服務的客戶內容數據都託管在資源配置所在的地區。對於 GitHub Actions 服務，Ubicloud 執行器預設在德國和芬蘭處理數據。在某些情況下，如果客戶明確請求啟用，工作負載可能會回退到美國。如果您需要為 Ubicloud 執行器啟用或停用特定地區，請透過 [support@ubicloud.com](mailto:support@ubicloud.com) 與我們的團隊聯繫。
